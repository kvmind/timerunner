Support

TimeRunner for Mac

A question, a problem or a request? Write it up and it will be answered.

Open a support request

Requests are kept on GitHub and are public: leave out client names and anything else that is private. Earlier ones are listed here.

Where is my data?

In one file on your Mac, in the app's own protected folder. Nothing is sent anywhere, and there is no account. See the privacy policy.

How do I back it up or move to another Mac?

Settings → Backup. The app keeps a copy for each day for about a month, on this Mac and in a folder you choose — iCloud Drive or Dropbox, say. On the other Mac, choose the same folder and restore the latest copy.

How do I add the widget?

Pin tasks in Settings → Pinned tasks, then right-click the desktop → Edit Widgets → TimeRunner. The Focus timer has widgets of its own in the same place.

How do I connect an AI tool?

Settings → MCP: switch the connector on and use the button for your tool — Claude, ChatGPT desktop, Codex, Cursor, VS Code and others. The connector is off until you switch it on, and a tool can read and add but never edit or delete.

The app asks for Touch ID. Can I switch that off?

Settings → Access → Biometric lock. It is off unless you switched it on.

Which Macs does it run on?

macOS 14 Sonoma or later, on Apple silicon and Intel.
