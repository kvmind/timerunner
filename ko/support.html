Mac용 TimeRunner

질문, 문제 또는 요청이 있으신가요? 내용을 적어 주시면 답변해 드립니다.

지원 요청 열기

요청은 GitHub에 보관되며 공개됩니다. 고객 이름 등 비공개 정보는 적지 마십시오. 이전 요청은 여기에서 볼 수 있습니다.

내 데이터는 어디에 있나요?

Mac에 있는 하나의 파일, 앱 전용 보호 폴더에 있습니다. 입력한 내용은 어디에도 전송되지 않으며 계정도 없습니다. 개인정보 처리방침(영어)을 참조하십시오.

백업하거나 다른 Mac으로 옮기려면 어떻게 하나요?

설정 → 백업. 앱은 하루에 하나씩, 약 한 달 치 사본을 이 Mac과 사용자가 선택한 폴더(예: iCloud Drive 또는 Dropbox)에 보관합니다. 다른 Mac에서 같은 폴더를 선택하고 최신 사본을 복원하십시오.

위젯은 어떻게 추가하나요?

작업 페이지에서 ‘위젯에 고정’, ‘대시보드에 고정’을 사용하거나 설정 → 고정된 작업에서 작업을 고정합니다. 그런 다음 데스크탑을 오른쪽 클릭 → 위젯 편집 → TimeRunner. 집중 타이머도 같은 곳에 전용 위젯이 있습니다.

AI 도구는 어떻게 연결하나요?

설정 → MCP에서 커넥터를 켜고 사용하는 도구(Claude, ChatGPT 데스크탑, Codex, Cursor, VS Code 등)의 버튼을 사용합니다. 그다음 평소 말로 요청하면 됩니다. 도구는 타이머 시작과 정지, 시간 기록, 고객·프로젝트·작업 만들기, 작업 완료, 프로젝트 보관, 통계·청구서·입금 내역 읽기를 할 수 있습니다. 커넥터는 켜기 전까지 꺼져 있으며, 읽기만 허용하려면 '읽기 전용'을 선택하세요. 커넥터를 통해서는 아무것도 삭제할 수 없고, 이미 만든 기록은 편집할 수 없습니다.

앱이 Touch ID를 요구합니다. 끌 수 있나요?

설정 → 앱 잠금 → 생체 인증 잠금. 직접 켜지 않았다면 꺼져 있습니다.

어떤 Mac에서 실행되나요?

Apple Silicon과 Intel, macOS 14 이상.

어떤 언어를 지원하나요?

영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 폴란드어, 벨라루스어, 일본어, 한국어. TimeRunner는 시스템 설정 → 일반 → 언어 및 지역 → 응용 프로그램에서 이 앱에 지정한 언어를 따릅니다.

가격은 얼마인가요?

TimeRunner는 무료로 다운로드할 수 있으며 첫 달에는 모든 기능이 무료입니다. 그 이후에는 월간, 연간 또는 평생 이용권 요금제로 계속 사용할 수 있습니다. 요금제를 참조하십시오. 가격은 구입 전에 앱과 App Store에 표시됩니다.

요금제가 없으면 어떻게 되나요?

TimeRunner는 읽기 전용이 됩니다. 기록은 Mac에 남아 계속 열고, 내보내고, 백업할 수 있지만 타이머를 시작하거나 항목을 추가·변경할 수는 없습니다.

TimeRunner가 무료였을 때 설치했습니다. 결제해야 하나요?

아니요. TimeRunner가 무료였을 때 설치된 사본은 모든 기능을 무료로 계속 유지합니다.

다른 Mac에서 구입 항목을 복원하려면?

App Store에서 같은 Apple 계정을 사용하고 설정 → 정보 → 구입 항목 복원을 선택하십시오.

구독은 어떻게 취소하나요?

설정 → 정보 → 구독 관리 또는 App Store 계정 설정에서 취소합니다. 취소는 이미 결제한 기간이 끝나는 시점에 효력이 발생합니다. 환불은 Apple이 처리합니다.
